Title trimming and Unicode code-point counting are shared by UI and HTTP validation. POST accepts only title. Responses use the required envelopes/statuses; storage exceptions become generic errors without SQL/path/stack details.
- Prepared SQLite statements bind all user-provided values. Schema creation is idempotent with no seed/delete path; creates and mutations return after synchronous writes. PATCH preserves ID/createdAt and correctly handles false completed values. DELETE of an absent ID yields 404. Database instances close in finally.

UI loads via API, updates rows only after successful mutation responses, retains add/edit inputs on failure, locks the corresponding pending control, and requires an explicit successful reload after unknown/404/server-error results. There is no automatic mutation retry or task localStorage.

Labels, native buttons/checkboxes, Vietnamese document language, field/alert error messaging and visible focus styles are present. HTML-like titles are React text nodes. Responsive CSS has wrapping and small-width row stacking. Actual visual/focus/browser behavior remains for stable acceptance evidence.
