# Shared Workflow Rules

This directory is the single source for rules shared across Compass stages.

- `design-principles.md` — choose an approach during planning.
- `compatibility.md` — assess backward compatibility during planning and review.
- `dependency-use.md` — evaluate dependency choices during planning and implementation.
- `code-quality.md` — guide implementation and review.
- `no-debug-artifacts.md` — inspect the final reviewed diff; temporary debugging is allowed during diagnosis and testing.
